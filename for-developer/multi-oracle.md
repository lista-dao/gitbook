# 多重预言机

## 弹性预言机存在的原因

单一价格馈送是单点故障：过时或被操纵的答案会导致不必要的清算或过大的贷款，而没有任何机制来捕捉这些问题。

弹性预言机通过为每种资产提供最多三个独立来源——**主**、**枢轴**和**后备**——并在返回价格之前相互交叉验证它们，从而消除了这一问题。被禁用、缺失、过时或回退的来源会被跳过，超出资产配置范围的价格会被拒绝而不是使用。可以为每种资产添加或切换来源而无需重新部署，因此资产的拓扑结构是配置而不是代码。

抵押资产正在逐步迁移到弹性预言机上，因此每种资产的来源集合不同——请阅读资产的配置而不是假设某种配置。
