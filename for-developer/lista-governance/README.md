# LISTA Governance

`LISTA` is the protocol's governance and incentive token.

> **veLISTA is retired under LIP-024.** New locking has been disabled on-chain since 2026-04-07 and governance voting has moved to plain LISTA on Snapshot. Existing locks can still be exited — see the Smart Contract page for the exit path and its one exception.
