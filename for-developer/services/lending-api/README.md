# Moolah 借贷 API

Lista Lending 所使用的 **Moolah 借贷协议 API** 的技术参考。该 API 面向客户端应用与集成方，提供协议级、金库、市场、仓位、清算与排放数据。

**Base URL：** `/api/moolah` 下的 `GET/POST`
