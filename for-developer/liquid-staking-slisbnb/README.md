# Liquid Staking (slisBNB)

Stake BNB through `ListaStakeManager` and receive **slisBNB**, a transferable ERC-20 that keeps earning validator rewards. slisBNB is yield-bearing by exchange rate rather than by rebase — the balance stays fixed and its BNB value grows.

It is also the most widely reused asset in the protocol: slisBNB is Moolah collateral (provider-gated), one side of a StableSwap pool, and the asset behind the `slisBNBx` Launchpool certificate.
