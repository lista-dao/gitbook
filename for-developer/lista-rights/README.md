# Lista Rights

Reward distribution for the **holder** emission programme — LISTA emissions routed to eligible holders rather than to lending or credit positions.

`LendingRewardsDistributorV2` and `RewardsRouter` are deployed once per emission programme, so the same two contract names appear on several pages. Match the programme, not the name: lending and bStock emission live on [BSC Core](../lista-lending/smart-contract-bsc-core.md), credit emission on [BSC Credit](../lista-lending/smart-contract-bsc-credit.md).
