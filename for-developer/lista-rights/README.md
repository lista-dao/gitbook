# Lista Rights

**持有者**发行计划的奖励分配——LISTA Holder Boost，是在符合条件的借贷存款/借款之上分层的额外发行，并根据持有者的LISTA余额等级加权（参见[持有者权益](../../governance/lista/lista-holder-benefits.md)），而不是作为借贷/信用头寸的替代奖励支付。

`LendingRewardsDistributorV2` 和 `RewardsRouter` 各自部署了多次，地址表并不总是说明是针对哪个发行计划。通过其所在页面识别合约：本节为持有者发行，[BSC Core](../lista-lending/smart-contract-bsc-core.md) 为借贷和bStock，[BSC Credit](../lista-lending/smart-contract-bsc-credit.md) 为信用。

* [智能合约](smart-contract.md) — 持有者发行的部署。
