# Lista Rights

**持有者**发行计划的奖励分配——LISTA 持有者提升计划，额外的发行层叠在符合条件的借贷存款/借款之上，并根据持有者的 LISTA 余额等级加权（参见 [持有者权益](../../governance/lista/lista-holder-benefits/)），而不是作为借贷/信用头寸的替代奖励支付。

`LendingRewardsDistributorV2` 和 `RewardsRouter` 各自被多次部署，地址表并不总是说明是针对哪个发行计划。通过其所在页面识别合约：本节为持有者发行，[BSC 核心](../lista-lending/smart-contract-bsc-core.md) 为借贷和 bStock，[BSC 信用](../lista-lending/smart-contract-bsc-credit.md) 为信用。

* [智能合约](smart-contract.md) — 持有者发行的部署。
