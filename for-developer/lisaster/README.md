# lisAster

**lisAster** (`Lista Staked Aster`) is Lista's liquid staking token for ASTER: stake ASTER through the vault, hold a transferable receipt, and keep earning.

Like slisBNB, it is reused across the protocol — lisAster/ASTER is a Lista StableSwap pool whose LP is accepted as Smart Lending collateral, priced by a custom feed rather than a market feed.

* [Smart Contract](smart-contract.md) — the token, vault, staking, rewards and distributor addresses.
