# RWA Markets

Real-World Asset (RWA) 市场提供了代币化的 RWA 购买，例如短期美国国债和抵押贷款义务，使用加密资产。这些 RWA 提供了具有不同风险水平的可预测利率。

### 工作原理

当下达购买订单时，Lista 将铸造相同价值的 RWA 代币并分发给买家。这些代币是收益型的，因此其价值会随着时间的推移而增加。每周二，Lista 将计算过去一周的利息并将其计入每个 RWA 代币的价格。请注意，Lista 将从赚取的利息中收取一小部分（目前为 5%）作为费用。

这些 RWA 代币也可以被销毁以赎回其价值并提取流动性。基础工具 - 美国国债、公司债务抵押等 - 只能在工作日出售，因此可能需要 5 到 14 天才能完成赎回。请注意，Lista 将对赎回收取 0.1% 的费用。

所有 RWA 代币的购买和赎回均通过 Janus Henderson Anemoy Treasury Fund（基金）处理，这是一个由 Centrifuge 提供支持的代币化英属维尔京群岛（BVI）专业基金。该基金由英属维尔京群岛金融服务委员会（FSC）许可，并向非美国投资者开放。

### Dowsure RWA Token

#### 产品详情

| 参数                    | 详情                    |
| ---------------------- | ----------------------- |
| 目标 APY               | \~10%                   |
| 锁定期                 | 90 天                   |
| 最低存款               | $100 USD                |
| 金库容量               | $3M（扩展至 $15M）      |
| 认购窗口               | 第 -7 天至第 0 天       |
| 历史坏账率             | < 1.5%（5 年平均）      |
| 自动续期               | 是（第 83 天前可选择退出）|

Lista 上的 Dowsure RWA 代币由三种基础资产支持：

1\. Payoneer Advance 这代表亚马逊跨境卖家的预结算应收款。像亚马逊这样的平台通常需要 14 天以上才能结算，而 Dowsure 提前向商家支付资金。周期范围为 14 至 28 天，流动性通常较高。

2\. Dowsure 的先买后付 大额采购（$500K+）的供应商发票融资。商家先收到货物，而 Dowsure 弥合支付差距。周期范围为 20 至 30 天。客户主要是贷款规模相当大的商家（通常超过 $500,000）。

3\. LOC 信用额度 Dowsure 的旗舰产品，具有 5 年的业绩记录。该产品为在亚马逊、eBay 和沃尔玛上年收入超过 $10M 的成熟电商商家提供信用额度。由汇丰银行、渣打银行、恒隆银行、招商银行、建设银行和多个基金提供资金。坏账率在 5 年内保持在 1.5% 以下。

### 安全与风险控制

* 3PAR 自动还款：3PAR 是由 Dowsure 与亚马逊、沃尔玛、eBay 和 Payoneer 共同开发的融资平台。在商家授权后，平台销售收益会在卖家正常结算前自动转至 Dowsure，确保从源头稳定还款。
* DAL 双锁：一种专利的资金控制系统，锁定商家支付账户，验证实际业务控制人，并在违约情况下启用资金冻结或强制扣款。
* KYC + AML 合规：对所有借款人完成全面的了解你的客户和反洗钱流程。

提前退出：您可以在第 90 天之前的任何时间提取 90% 的本金（根据质押天数的收益罚款）。剩余的 10% 将保留至第 90 天，并在坏账审核后释放。

坏账政策：如果坏账率超过 4% APY，超出部分将从用户收到的收益中扣除。5 年历史平均值低于 1.5%。
