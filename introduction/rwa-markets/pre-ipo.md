# Pre-IPO

Lista DAO 正在为预测市场的领先名称之一 **Kalshi** 开启 pre-IPO 认购，该发行通过 Paimon 进行。Lista DAO 社区的合格成员可以在 Kalshi 公开上市之前进行链上认购。分配是有限的，认购窗口期很短，将于 7 月 28 日当周开放。本文详细介绍了完整的规则、时间表和机制。

**所有时间均为 UTC（UTC+0）。**

***

您通过在一轮中存入 USDT 来认购。当它关闭时，分配是**按存款比例**共享的，而不是通过抽签或先到先得。

认购最多进行两轮：仅对合格的 Lista 用户开放的**白名单轮**，按活动等级加权，然后是对所有人开放的**公开轮**，仅在白名单轮后仍有剩余分配时进行。

## **2. 选择您的部分** <a href="#h-2-choose-your-tranche" id="h-2-choose-your-tranche"></a>

在您的首次存款时，您选择两个部分之一。**此选择是最终的**：每次后续充值都遵循此选择，并且在结算前无法更改。

|                      | **$xKLSH（解锁）**                   | **$pKLSH（锁定）**                                                                                                                           |
| -------------------- | --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **锁定期**          | 无；您认领后即可转让 | 6 个月；不可转让                                                                                                                    |
| **您收到的内容** | 每分配 $39 获得一个代币             | 每分配 $39 获得一个代币，成熟时按 1 : 1.4 转换为 $xKLSH                                                                       |
| **交付**         | 结算后在 Lista 上认领       | 无需认领步骤。Lista 提交您的分配给 Paimon，Paimon 注册并在成熟时直接将转换后的 $xKLSH 发送到您的钱包 |

<br>

锁定部分的 1.4 倍指的是**代币数量**：成熟时，每个 $pKLSH 转换为 1.4 $xKLSH，比原来多 40% 的代币。&#x20;

## **4. 第 1 轮：白名单轮（7 月 28 日至 29 日）** <a href="#h-4-round-1-whitelist-round-july-28-to-29" id="h-4-round-1-whitelist-round-july-28-to-29"></a>

白名单轮对 Lista 的最活跃用户开放。您的资格和分配权重基于认购开放前的活动，考虑到您在 Lista Lending 和 Smartlending 上的借款以及您的 LISTA 持有量。更高的活动获得更高的分配权重，请查看 [Pre-IPO 页面](https://lista.org/pre-ipo/1) 以获取您的分配详情。

您的快照是在认购开放前拍摄的，因此认购窗口期间的任何活动都不会影响您的资格或权重。您的状态显示在认购页面上。

### **白名单等级和权重**  <a href="#h-whitelist-levels-and-weights" id="h-whitelist-levels-and-weights"></a>

<br>

| **等级**  | **权重** | **描述**                                                          |
| ---------- | ---------- | ------------------------------------------------------------------------ |
| L1         | 2x         | 深度借款人（大额、长期）                                        |
| L2         | 1.5x       | 活跃借款人或大持有人                                        |
| L3         | 1x         | 90 天平均得分为 ≥ $100（借款）或 ≥ $300（持有）的钱包 |

\
_您的等级是根据过去 90 天的借款金额和 Lista 持有量评估的。纯持有者钱包（无未偿借款金额）最高为 L2 – 达到 1 级需要有借款历史_

**\*如果您有合格的头寸但不在白名单上，请通过我们的官方** [**Telegram 频道**](https://linktr.ee/lista_dao) **联系我们**

### **白名单轮中的分配方式** <a href="#h-how-allocation-works-in-the-whitelist-round" id="h-how-allocation-works-in-the-whitelist-round"></a>

* **如果总存款为 $1,000,000 或更少：** 每个参与者都会收到其全额存款，最高可达 $100,000 的上限。任何剩余的分配将转移到公开轮。
* **如果总存款超过 $1,000,000：** 分配按加权存款分配，如下所示。

_加权存款 = 您的存款 × 您的等级权重_

_您的分配 = (您的加权存款 ÷ 总加权存款) × $1,000,000_

您的分配永远不会超过您存入的金额，并且上限为 $100,000。任何超过您分配的存款将全额退款。

随着轮次的进行，存款页面会显示您预计分配和退款的实时估算。

## **5. 第 2 轮：公开轮（7 月 30 日，条件）** <a href="#h-5-round-2-public-round-july-30-conditional" id="h-5-round-2-public-round-july-30-conditional"></a>

### **开放时间** <a href="#h-when-it-opens" id="h-when-it-opens"></a>

仅在白名单轮未填满全部 $1,000,000 时进行公开轮。页面显示确切的剩余分配。如果白名单轮已全部认购，则不进行公开轮。

### **谁可以参与** <a href="#h-who-can-participate" id="h-who-can-participate"></a>

所有用户。白名单参与者可以增加其存款，前提是其在两轮中的总分配不超过 $100,000 的上限。

**重要：** 如果您在白名单轮中已获得分配，您在公开轮中的个人限制为 $100,000 的上限减去您已获得的分配。&#x20;

### **公开轮中的分配方式** <a href="#h-how-allocation-works-in-the-public-round" id="h-how-allocation-works-in-the-public-round"></a>

公开轮不适用等级权重；分配仅按存款大小分配。

* **如果总存款在剩余分配范围内：** 每个参与者都会收到其全额存款，最高可达上限。
* **如果总存款超过剩余分配：** 每个参与者收到 (剩余分配 ÷ 总存款) × 其存款，余额将被退款。

### **示例** <a href="#h-worked-example" id="h-worked-example"></a>

剩余分配为 $150,000，两名用户各存入 $100,000（总计 $200,000，超额认购）。填充率为 150,000 ÷ 200,000 = 75%。每个用户分配 $75,000 并退款 $25,000。

## **6. 结算和认领** <a href="#h-6-settlement-and-claiming" id="h-6-settlement-and-claiming"></a>

**结算（7 月 31 日）。** 结算完成后，您的最终分配和退款将显示在认购页面上。

**认领（从 8 月 1 日起）。**

* **$xKLSH 和退款：** 在 Lista 认购页面上认领。认领不会过期。
* **$pKLSH：** Lista 提交您的锁定分配（地址、分配的 USDT、$pKLSH 数量）给 Paimon，Paimon 注册它。在成熟时（大约在结算后六个月），Paimon 直接将转换后的 $xKLSH 发送到您的钱包 — 您无需采取任何行动。在此之前，[Pre-IPO 页面](https://lista.org/pre-ipo/1) 显示您的注册金额、成熟日期和应得数量。

**重要：** 使用自我托管的 BNB Chain 钱包，而不是交易所存款地址。由于 $pKLSH 在成熟时直接发送到您的地址，发送到交易所地址的代币可能会丢失。
